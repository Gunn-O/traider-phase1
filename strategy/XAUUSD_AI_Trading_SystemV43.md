### 1.2 เทรนขึ้น (Uptrend)

#### นิยาม
กราฟที่มีการยก **Higher Low** และ **Higher High** ขึ้นต่อเนื่องอย่างชัดเจนใน 55 แท่งที่สนใจ โดยผ่านการตรวจย้อนกลับ 25 แท่งก่อนหน้าแล้ว

#### เกณฑ์การระบุ — 2 ขั้นตอน

**ขั้นที่ 1: ตรวจ 55 แท่งที่สนใจ**
- มี HH/HL ต่อเนื่องชัดเจน
- ความชันเฉลี่ย 45-50 องศา
- คำนวณ Range55 จาก window นี้

**ขั้นที่ 2: ตรวจย้อนกลับ 25 แท่งก่อนหน้า**
```
เลื่อน window ย้อนกลับ 25 แท่ง
→ ได้ Shifted Window 55 แท่งใหม่ (เริ่มก่อนหน้า 25 แท่ง)
→ คำนวณ Range55 ของ Shifted Window นี้
→ ใช้ Range55 ใหม่ประเมิน 25 แท่งแรกของ Shifted Window

ตรวจว่า 25 แท่งแรกนั้น:
  ไม่มีแรงขายรุนแรง / ไม่มีเทรนลงต่อเนื่อง
  → ✅ เทรนขึ้น 55 แท่งที่สนใจ ใช้ได้

  มีแรงขายรุนแรง / มีเทรนลงต่อเนื่อง ในสัดส่วนของ Range55 ใหม่
  → ❌ 55 แท่งที่สนใจอาจแค่ "เริ่มขึ้น" → ยังใช้ไม่ได้
```

> 💡 **ตัวอย่าง:**
> สนใจ 12:55–17:30 (55 แท่ง) → เลื่อนย้อน 25 แท่ง → Shifted Window = 10:50–15:25
> คำนวณ Range55 ของ 10:50–15:25 → ตรวจ 25 แท่งแรก (10:50–12:50)
> ไม่มีแรงขายรุนแรง → ✅ เทรนขึ้น 12:55–17:30 ใช้ได้

- ใช้ได้กับทุก Timeframe: M1, M5, M15, M30, H1, H4

#### นิยาม HH และ HL ที่ถูกต้อง

> ⚠️ **สำคัญ:** HH และ HL ไม่ใช่จุดราคาสูงสุด/ต่ำสุดทั่วไป แต่ต้องอ่านจาก **แท่งคู่เท่านั้น** และวัดจาก **เนื้อเทียน ไม่นับไส้เทียน**

| จุด | คืออะไร | วิธีวัด |
|-----|---------|--------|
| **HH (Higher High)** | แท่งคู่ที่ body_hi สูงกว่า HH ก่อนหน้า | วัดที่ **บนสุดของเนื้อเทียน** (max ของ Open/Close) |
| **HL (Higher Low)** | แท่งคู่ที่ body_lo สูงกว่า HL ก่อนหน้า | วัดที่ **ล่างสุดของเนื้อเทียน** (min ของ Open/Close) |

**ไม่นับไส้เทียน** → ไส้เทียนใช้สำหรับวาง SL เท่านั้น ไม่ใช้ระบุ HH/HL

#### วิธีหา Swing Point (HH/HL) ที่ถูกต้อง

> **Swing Point คือจุดที่ราคาเปลี่ยนทิศจริงๆ ในโครงสร้างกราฟ** ไม่ใช่การแบ่งช่วงเวลาเท่ากัน

```
Swing High (HH candidate):
  แท่งคู่ที่ body_hi สูงกว่าแท่งก่อนหน้าและถัดไปอย่างชัดเจน
  = จุดที่ราคาขึ้นถึงแล้วหยุดและวกลง

Swing Low (HL candidate):
  แท่งคู่ที่ body_lo ต่ำกว่าแท่งก่อนหน้าและถัดไปอย่างชัดเจน
  = จุดที่ราคาลงถึงแล้วหยุดและวกขึ้น
```

**ตัวอย่างการระบุ HH/HL ตามโครงสร้างจริง:**
```
ลำดับที่เกิดขึ้นจริง:
  HH1 (14:40–14:45) = 4,845.615  ← swing high จุดแรก
  HL1 (15:05–15:10) = 4,833.495  ← swing low หลัง HH1
  HH2 (16:35–16:40) = 4,882.615  ← swing high สูงกว่า HH1 ✅
  HL2 (17:05–17:10) = 4,876.485  ← swing low สูงกว่า HL1 ✅
  HH3 (19:10–19:15) = 4,923.945  ← swing high สูงกว่า HH2 ✅
  HL3 (19:45–19:50) = 4,908.055  ← swing low สูงกว่า HL2 ✅
  HH4 (20:20–20:25) = 4,927.175  ← swing high สูงกว่า HH3 ✅
  HL4 (21:00–21:05) = 4,916.055  ← swing low สูงกว่า HL3 ✅

→ เทรนขึ้นชัดเจน ทุกจุดยก HH/HL ต่อเนื่อง
```

> ⚠️ Swing Point อาจ span ได้ถึง ~80 แท่ง (55 แท่งที่สนใจ + 25 แท่ง shifted)
> Range55 ยังคงคำนวณจาก 55 แท่งปัจจุบันเท่านั้น

#### วิธีนับ HH/HL — อ่านเป็นคู่

> ตรวจเกณฑ์เฉพาะ **คู่หลังสุด** ที่เกิดขึ้นใน 55 แท่งปัจจุบัน

```
Starting points (คู่แรกๆ) = ไม่ตรวจ % Range55
คู่หลังสุด (HHn / HLn)   = ตรวจว่าอยู่เหนือ 50% หรือ 70% ของ Range55

ตัวอย่าง (ณ 21:05):
  Range55 (16:30→21:05) = 5,910 pip | 70% = 4,910.565
  HL4 = 4,916.055 → 79.3% ✅ > 70% → สวย 100%
  HH4 = 4,927.175 → 98.1% ✅ > 70% → สวย 100%
```

#### เกณฑ์ความชัดเจน

| ระดับ | เงื่อนไข | การตัดสินใจ |
|-------|---------|------------|
| **สวย 100%** | HH2 และ HL2 อยู่สูงกว่า **70%** ของ Range55 + ความชัน 45-50° | ✅ เข้าเทรดได้ |
| **สวย ~60%** | HH2 หรือ HL2 อยู่สูงกว่า **50%** แต่ต่ำกว่า 70% ของ Range55 | ❌ หลีกเลี่ยง รอดีกว่า |
| **ไม่นับ** | HH2 หรือ HL2 อยู่ต่ำกว่า **50%** ของ Range55 | ❌ ไม่ใช่เทรนขึ้น |

> 💡 **หลักการ:** ยิ่งหลุดออกจากความชันอ้างอิง ความสวยยิ่งลดลงตามลำดับ รอเฉพาะ Setup สวย 100%

#### โครงสร้าง
```
[ช่วงที่ 1] ตัวเทรน → ยก Low ยก High ชัดเจน ความชัน 45-50 องศา
[ช่วงที่ 2] พักตัวหลังเทรน → รอหาแท่งคู่ (กรอบสดใหม่) เพื่อเข้า BUY
```

#### เทคนิคการเข้า BUY ใน Uptrend มี 2 แบบ

| แบบ | เทคนิค | วิธี |
|-----|--------|------|
| **1** | **แท่งคู่** | รอราคาย่อมาแตะแท่งคู่ → เข้า BUY |
| **2** | **ตามเจ้า** | ระหว่างเทรนราคาพักสร้างกรอบเล็กๆ → รอปิดหลุดกรอบบน → เข้า BUY ทันที |

### 1.3 เทรนลง (Downtrend)

#### นิยาม
กราฟที่มีการกด **Lower High** และ **Lower Low** ลงต่อเนื่องอย่างชัดเจนใน 55 แท่งที่สนใจ โดยผ่านการตรวจย้อนกลับ 25 แท่งก่อนหน้าแล้ว — **ทุกอย่างกลับทางจากเทรนขึ้น**

#### เกณฑ์การระบุ — 2 ขั้นตอน

**ขั้นที่ 1: ตรวจ 55 แท่งที่สนใจ**
- มี LH/LL ต่อเนื่องชัดเจน
- ความชันเฉลี่ย 45-50 องศา
- คำนวณ Range55 จาก window นี้

**ขั้นที่ 2: ตรวจย้อนกลับ 25 แท่งก่อนหน้า**
```
เลื่อน window ย้อนกลับ 25 แท่ง
→ ได้ Shifted Window 55 แท่งใหม่ (เริ่มก่อนหน้า 25 แท่ง)
→ คำนวณ Range55 ของ Shifted Window นี้
→ ใช้ Range55 ใหม่ประเมิน 25 แท่งแรกของ Shifted Window

ตรวจว่า 25 แท่งแรกนั้น:
  ไม่มีแรงซื้อรุนแรง / ไม่มีเทรนขึ้นต่อเนื่อง
  → ✅ เทรนลง 55 แท่งที่สนใจ ใช้ได้

  มีแรงซื้อรุนแรง / มีเทรนขึ้นต่อเนื่อง ในสัดส่วนของ Range55 ใหม่
  → ❌ 55 แท่งที่สนใจอาจแค่ "เริ่มลง" → ยังใช้ไม่ได้
```

- ใช้ได้กับทุก Timeframe: M1, M5, M15, M30, H1, H4

#### นิยาม LH และ LL ที่ถูกต้อง

> ⚠️ **สำคัญ:** LH และ LL ไม่ใช่จุดราคาสูงสุด/ต่ำสุดทั่วไป แต่ต้องอ่านจาก **แท่งคู่เท่านั้น** และวัดจาก **เนื้อเทียน ไม่นับไส้เทียน**

| จุด | คืออะไร | วิธีวัด |
|-----|---------|--------|
| **LL (Lower Low)** | แท่งคู่ที่ body_lo ต่ำกว่า LL ก่อนหน้า | วัดที่ **ล่างสุดของเนื้อเทียน** (min ของ Open/Close) |
| **LH (Lower High)** | แท่งคู่ที่ body_hi ต่ำกว่า LH ก่อนหน้า | วัดที่ **บนสุดของเนื้อเทียน** (max ของ Open/Close) |

**ไม่นับไส้เทียน** → ไส้เทียนใช้สำหรับวาง SL เท่านั้น ไม่ใช้ระบุ LH/LL

#### วิธีหา Swing Point (LH/LL) ที่ถูกต้อง

> **Swing Point คือจุดที่ราคาเปลี่ยนทิศจริงๆ ในโครงสร้างกราฟ** — Mirror จากเทรนขึ้นทุกอย่าง

```
Swing Low (LL candidate):
  แท่งคู่ที่ body_lo ต่ำกว่าแท่งก่อนหน้าและถัดไปอย่างชัดเจน
  = จุดที่ราคาลงถึงแล้วหยุดและวกขึ้น

Swing High (LH candidate):
  แท่งคู่ที่ body_hi สูงกว่าแท่งก่อนหน้าและถัดไปอย่างชัดเจน
  = จุดที่ราคาขึ้นถึงแล้วหยุดและวกลง
```

#### วิธีนับ LH/LL — อ่านเป็นคู่

> ตรวจเกณฑ์เฉพาะ **คู่หลังสุด** ที่เกิดขึ้นใน 55 แท่งปัจจุบัน

```
Starting points (คู่แรกๆ) = ไม่ตรวจ % Range55
คู่หลังสุด (LLn / LHn)   = ตรวจว่าอยู่ต่ำกว่า 50% หรือ 30% ของ Range55
```

#### เกณฑ์ตำแหน่งของ LH/LL ใน Range55

> ตรวจเฉพาะ **คู่หลังสุด (LLn / LHn)** ที่อยู่ใน 55 แท่งปัจจุบัน

```
เส้นกึ่งกลาง (50%) = Low55 + (Range55 × 50%)
เส้น 30%           = Low55 + (Range55 × 30%)

LLn/LHn อยู่ต่ำกว่า 30% ของ Range55 → สวย 100% ✅ เข้าเทรดได้
LLn/LHn อยู่ต่ำกว่า 50% แต่สูงกว่า 30% → สวย ~60% ⚠️ หลีกเลี่ยง รอดีกว่า
LLn/LHn อยู่สูงกว่า 50% ของ Range55 → ไม่นับเป็นเทรนลง ❌
```

#### เกณฑ์ความชัดเจน

| ระดับ | เงื่อนไข | การตัดสินใจ |
|-------|---------|------------|
| **สวย 100%** | LLn และ LHn อยู่ต่ำกว่า **30%** ของ Range55 + ความชัน 45-50° | ✅ เข้าเทรดได้ |
| **สวย ~60%** | LLn หรือ LHn อยู่ต่ำกว่า **50%** แต่สูงกว่า 30% ของ Range55 | ❌ หลีกเลี่ยง รอดีกว่า |
| **ไม่นับ** | LLn หรือ LHn อยู่สูงกว่า **50%** ของ Range55 | ❌ ไม่ใช่เทรนลง |

> 💡 **Mirror กับเทรนขึ้น:** เทรนขึ้น ตรวจ HHn/HLn > 70% (upper zone) / เทรนลง ตรวจ LLn/LHn < 30% (lower zone)

#### ความแตกต่างจากไซเวย์กดลง

| | เทรนลง | ไซเวย์กดลง |
|--|--------|-----------|
| **ลักษณะขาลง** | ทยอยลงเรื่อยๆ สม่ำเสมอ | ลงแรงและเร็ว 3-10 แท่ง |
| **ระยะขาลง** | ค่อยๆลง วกขึ้นแล้วลงต่อ | 80-100% ของ Range ในคราวเดียว |
| **หลังขาลง** | ยังคงลงต่อเรื่อยๆ | เกิด Sideway กรอบบน-ล่าง |

#### หลักการ
เน้นหาจังหวะเข้า **SELL เท่านั้น** โดยรอราคาดีดขึ้นมาแตะแท่งคู่ด้านบน

#### เทคนิคการเข้า SELL ใน Downtrend มี 2 แบบ

| แบบ | เทคนิค | วิธี |
|-----|--------|------|
| **1** | **แท่งคู่** | รอราคาดีดขึ้นมาแตะแท่งคู่ → เข้า SELL |
| **2** | **ตามเจ้า** | ระหว่างเทรนราคาพักสร้างกรอบเล็กๆ → รอปิดหลุดกรอบล่าง → เข้า SELL |

#### จุดเข้า SELL — แท่งคู่

```
จุดเทคนิค = เนื้อเทียนด้านบนของแท่งคู่ (body_hi)

เกณฑ์คุณภาพ LH ที่ดี (ตรวจก่อนรอเข้า):
  ระยะดีด = LH ปัจจุบัน − LL ก่อนหน้า
  สัดส่วน = ระยะดีด ÷ Range55 × 100%
  10–30% → LH สวย ✅ รอเข้าได้
  < 10%  → ดีดน้อยเกิน ❌
  > 30%  → ดีดสูงเกิน ❌

Buffer    = 100 pip (fixed)
Entry Zone = [จุดเทคนิค − 100pip  →  จุดเทคนิค + 100pip]

เงื่อนไขเข้า SELL:
  ราคา (ไส้เทียน) แตะเข้ามาใน Zone
  → เข้า SELL ทันที ไม่ต้องรอปิดแท่ง
  Entry จริง = ราคาที่ไส้เทียนแตะ Zone (ขอบล่างของ Zone)
```

#### SL — แท่งคู่ SELL

| จุด SL | วิธีคำนวณ |
|--------|-----------|
| **SL1** | เลยปลายไส้สูงสุดของแท่งคู่ + **10% ของ Range** |
| **SL2** | อยู่ในไส้บน (ใช้เมื่อไส้ > 35% ของ Range55) |
| **SL3** | เลยไส้กลุ่มแท่งก่อนหน้าที่ยาวที่สุด + **10% ของ Range** |

#### TP — แท่งคู่ SELL

| จุด TP | วิธีคำนวณ |
|--------|-----------|
| **TP1** | จุดเข้า − **30-40%** ของระยะ (จุดเทคนิค → ฐานก่อนหน้า) |
| **TP2** | จุดเข้า − **50%** ของระยะเดียวกัน |
| **TP3** | สูงกว่าเนื้อเทียนล่าง LL ก่อนหน้าเล็กน้อย |

> กฎ: TP ต้องอยู่ **สูงกว่าอุปสรรค** (แท่งคู่, ไส้เทียน, จุด High เก่า) เสมอ

#### ตามเจ้า SELL — Criteria ครบ 3 รูปแบบ

```
หลักการตีกรอบ (SELL):
  กรอบล่าง = Swing Low แท่งคู่ล่าสุด (body_lo)   ← จุด Trigger
  กรอบบน  = Swing High แท่งคู่ล่าสุด (body_hi)   ← จุดวัด SL
  ขนาดกรอบ ≤ 35% ของ Range55

เงื่อนไข 2 จุดสัมผัส (SELL สนใจกรอบล่าง):
  กรอบล่างต้องมี Swing Low ≥ 2 จุด
  โดย body_lo ของ 2 จุดนั้น ห่างกัน ≤ 5% ของ Range55
  จุด Breakout = body_lo ต่ำสุดของ 2 จุดนั้น
  (กรอบบน ใช้ Swing High ล่าสุดเพียง 1 จุดก็พอ)

  ถ้ากรอบล่างมีจุดสัมผัสแค่ 1 จุด → ยังไม่เป็นกรอบที่ใช้ตามเจ้าได้ ❌

นิยามสั้น vs ยาว (SELL):
  ระยะหลุด = กรอบล่าง − Close แท่ง Breakout
  สัดส่วน  = ระยะหลุด ÷ ขนาดกรอบ × 100%

  < 5%      → ยังไม่นับว่า Breakout ❌
  5%–35%    → คอนเฟิร์มสั้น → เปิดทันทีแท่งถัดไป
  > 35%     → คอนเฟิร์มยาว → รอดีดขึ้นก่อนเข้า
              จุด 1 = ครึ่งแท่งที่หลุดกรอบ | จุด 2 = บริเวณกรอบล่าง

TP (เลือก 1):
  TP1 = จุดเข้า − 1/3 ของขนาดกรอบ
  TP2 = จุดเข้า − 1/2 ของขนาดกรอบ
  TP3 = จุดเข้า − ขนาดกรอบเต็ม

SL — วัดจาก กรอบล่าง ขึ้นไป (ไม่ใช่วัดจากจุดเข้า):
  ตามเจ้าในแท่ง:       SL = กรอบล่าง + 1/3 ของขนาดกรอบ
  คอนเฟิร์มสั้น:       SL = กรอบล่าง + 1/2 ของขนาดกรอบ
                        หรือ กรอบล่าง + 70% ของขนาดกรอบ
  คอนเฟิร์มยาว:        SL = กรอบล่าง + 1/3 หรือ 1/2 ของขนาดกรอบ

กฎเลือก R:R:
  เลือก SL ที่ให้ R:R ใกล้เคียง 1 ที่สุด แต่ไม่ต่ำกว่า 1.0
  = เลือก SL ที่ใหญ่ที่สุดโดยยัง R:R ≥ 1.0
```

### 1.6 ภูเขา (Mountain)

#### นิยาม
ราคาขึ้นและลงภายใน 55 แท่ง ก่อตัวเป็นรูปสามเหลี่ยม

> ⚠️ **เงื่อนไขขั้นต่ำ:** ความสูงภูเขา (ฐานถึงยอด) ต้อง **> 50% ของ Range 55 แท่ง**

#### การวัดความสูงภูเขา (Setup Size)

> ⚠️ **สำคัญ:** วัดจาก **เนื้อเทียนของแท่งคู่เท่านั้น** ไม่นับไส้เทียน

```
ฐานภูเขา (ซ้าย) = เนื้อเทียนล่างสุด (min Open/Close) ของแท่งคู่ฐาน
ยอดภูเขา        = เนื้อเทียนบนสุด (max Open/Close) ของแท่งคู่ยอด
ความสูงภูเขา    = ยอดภูเขา − ฐานภูเขา
```

#### ลักษณะภูเขาที่ดี
- รูปร่างสามเหลี่ยมชัดเจน ยอดไม่แบน — **ยิ่งใกล้เคียงสามเหลี่ยมมากยิ่งสวย**
- ความสูงภูเขายิ่งสูงยิ่งสวย — **ขนาดใกล้เคียง 100% ของ Range = สวยที่สุด**
- ราคากลับมาถึงฐาน **ภายในไม่เกิน 40 แท่ง** = สวย
- **ฐานด้านซ้าย** = แท่งคู่หนา ≥ 5% ของ Range → **จุดเทคนิค**
- **ฐานด้านขวา** = จุดที่ราคาลงมาถึงและเสมอกับแนวฐานด้านซ้าย → **จุดรอเข้า BUY**

#### Buffer Zone (ภูเขา)

```
Buffer = min(ความสูงภูเขา × 10%, 100 pip)

หมายเหตุ: Cap ของ Buffer ภูเขา = 100 pip
          (ต่างจาก Setup อื่นที่ cap 300 pip)
```

> 💡 **Tolerance ฐานภูเขา:** ยอมรับราคาห่างจากฐานซ้ายได้ไม่เกิน Buffer เท่านั้น
> ถ้าราคายังสูงกว่า Buffer = ยังไม่ถือว่าถึงฐาน → รอต่อ

#### หลักการในสถานการณ์จริง
- เห็นเพียง **ฝั่งซ้าย (ขาขึ้น)** เท่านั้น
- รอราคาลงมาถึงระดับ **เสมอกับฐานด้านซ้าย** → จุดเข้า
- คำนวณ TP/SL จาก **ข้อมูลฝั่งซ้ายทั้งหมด**
- ใช้เล่น **BUY เท่านั้น**

#### สัญญาณเข้า BUY ภูเขา

**มีลักษณะเดียวเท่านั้น:**
> ราคาขาขวาลงมาถึงระดับ **เสมอกับฐานด้านซ้าย** → เข้า BUY ทันที ไม่ว่าจะเกิดไม้รวยหรือไม่ก็ตาม

---

#### ความสัมพันธ์ระหว่างภูเขาและไม้รวย

ไม้รวยอาจเป็น**ส่วนประกอบ**ของภูเขาได้ — ภูเขาอาจมีหรือไม่มีไม้รวยก็ได้

> 💡 **ภูเขาที่ขาลงปลายเป็นไม้รวย → ความแม่นยำสูงขึ้น**

**การเกิดไม้รวยร่วมกับภูเขามี 2 แบบ:**

**แบบที่ 1:**
ราคาลงมาเสมอฐานซ้าย → **เกิดแท่งแม่บริเวณฐานขวา** → ราคาขึ้น

**แบบที่ 2:**
ราคาลงมาใกล้ฐานซ้าย → **เกิดแท่งแม่ก่อน** → ราคา Swing ลงมาจนเสมอฐานซ้าย → ราคาขึ้น

> ⚠️ ทั้ง 2 แบบ จุดเข้า BUY ยังคงเป็น **เมื่อราคาเสมอฐานซ้าย** เหมือนกัน

---

#### จุดเข้า BUY

| จุด | ตำแหน่ง | หมายเหตุ |
|-----|---------|---------|
| **จุดที่ 1** | เนื้อแท่งคู่ฐาน หรือใกล้เคียง | ไม่ควรลอยเกิน Buffer |
| **จุดที่ 2** | ตรงเนื้อแท่งคู่ฐานพอดี | **จุดเทคนิค** |
| **จุดที่ 3** | ต่ำกว่าแท่งคู่ฐานลงมา | **จุดได้เปรียบ** |

#### TP

| จุด TP | ตำแหน่ง |
|--------|---------|
| **TP1** | 1/3 ของความสูงภูเขา |
| **TP2** | 1/2 ของความสูงภูเขา |
| **TP3** | เกือบถึงยอดสุดของภูเขา (เนื้อเทียนยอด) |
| **TP อื่นๆ** | ถ้ามีอุปสรรค → เก็บต่ำกว่าอุปสรรคเล็กน้อย |

#### SL

| จุด SL | วิธีคำนวณ |
|--------|---------|
| **SL1** | ห่างจากจุดเทคนิค **10-20% ของ Range** |
| **SL2** | เลยปลายไส้เทียนล่างแท่งคู่ฐาน ออกไป **10% ของ Range** |
| **SL3** | ถ้ามีไส้ก่อนหน้ายาวกว่า → ตั้ง SL เผื่อออกไปจากไส้ที่ยาวที่สุด |

> ⚠️ SL2 เปลี่ยนจาก 5% เป็น **10%** ของ Range เพื่อให้ปลอดภัยขึ้น
> ถ้าไส้ก่อนหน้ายาวมาก → ไม่เล่นจุดนั้น หรือรอราคานิ่งก่อนแล้วค่อยเข้าจุดได้เปรียบ

### 1.7 ไม่ชัด (Unclear)
ทรงกราฟที่ไม่เข้าข่ายลักษณะใดใน 5 แบบข้างต้น → **ไม่เทรดตามเทรน**

#### สิ่งที่ทำได้เมื่อกราฟไม่ชัด

แม้กราฟจะไม่ชัด แต่ยังมี Setup ที่สามารถรอเล่นได้ 2 แบบ:

| Setup | เงื่อนไข |
|-------|---------|
| **ไม้รวย** | รอให้เกิดแท่งพ่อที่ชัดเจน แล้วรอแท่งแม่สวน → เข้า**สวนทิศทางแท่งพ่อ** (แท่งพ่อพุ่งขึ้น = เปิด SELL / แท่งพ่อพุ่งลง = เปิด BUY) |
| **แนวเด้ง** | รอให้ราคาวิ่งมาแตะแนวรับ/แนวต้านที่ชัดเจน → เข้าเมื่อราคาเด้งกลับ |

> 💡 **หลักการ:** กราฟไม่ชัด ≠ ไม่มีโอกาส — แค่เปลี่ยนวิธีมองจากการตามเทรน มาเป็นรอ Setup เฉพาะจุดแทน

#### กฎการใช้ไม้รวยกับกราฟไม่ชัด — เพิ่มเติม

เมื่อกราฟไม่ชัด และเห็น**การพุ่งของราคาแรงๆ ในช่วงราคาล่าสุด** → รอเล่น **ไม้รวย** ได้เลย

| แท่งพ่อ | ทิศทางที่เล่น | เงื่อนไข |
|--------|-------------|---------|
| ราคา**พุ่งขึ้น**แรง | รอเปิด **SELL** | ต้องไม่มีเทรนขึ้นชัดเจนก่อนหน้า |
| ราคา**พุ่งลง**แรง | รอเปิด **BUY** | ต้องไม่มีเทรนลงชัดเจนก่อนหน้า |

### 2.0.1 การวาง TP

### 2.1 นิยาม "แท่งคู่" — มี 2 บทบาท

> 💡 **Window 55 แท่ง:** ใช้ 55 แท่งเสมอ (แท่ง 1-55, 2-56, 3-57 ...) คำนวณ Range55 จาก window ปัจจุบันก่อน แล้วค่อยหา Swing Point

**บทบาทที่ 1 — ระบุ Swing Point (HH/HL/LH/LL):**
1. Open หรือ Close ของ 2 แท่ง ห่างกัน **ไม่เกิน 50 pip**
2. เนื้อเทียน (|Open-Close|) แต่ละแท่ง **≥ 1% ของ Range55**

**บทบาทที่ 2 — Entry Setup (จุดเข้าเทรด):**
1. Open หรือ Close ของ 2 แท่ง ห่างกัน **ไม่เกิน 20 pip**
2. เนื้อเทียน (|Open-Close|) แต่ละแท่ง **≥ 3% ของ Range55**

**คะแนนความสวยของแท่งคู่ Entry** (ใช้ body แท่งที่เล็กกว่าในคู่เป็นเกณฑ์):

| body แท่งคู่ | ความสวย |
|-------------|---------|
| > 3% R55 | สวย 60% ⚠️ |
| > 4% R55 | สวย 80% 🔶 |
| > 5% R55 | สวย 90% ✅ |
| > 7% R55 | สวย 100% ✅✅ |

### 2.1.1 วิธีระบุ Swing Point (HH/HL/LH/LL) จากแท่งคู่

```
ขั้นตอน:
  1. หาแท่งคู่ที่ผ่านเงื่อนไข Swing (ห่าง ≤ 50pip, body ≥ 1%R55)
  2. คำนวณค่าเฉลี่ยจุดต่อ = (C1 + O2) ÷ 2
       C1 = Close ของแท่งแรก
       O2 = Open ของแท่งที่สอง
  3. ตรวจแท่งข้างเคียง ซ้าย 3 แท่ง + ขวา 2 แท่ง

Swing High (HH หรือ LH):
  (C1+O2)÷2 > Open และ Close ของทุกแท่งข้างเคียง ✅

Swing Low (HL หรือ LL):
  (C1+O2)÷2 < Open และ Close ของทุกแท่งข้างเคียง ✅
```

```
ตัวอย่าง LH ที่ 01:45-01:46 (M1 V9):
  C1 = Close 01:45 = 4813.455
  O2 = Open  01:46 = 4813.485
  (C1+O2)÷2 = 4813.470

  ซ้าย 3 (01:42-01:44): OC สูงสุด = 4813.195 < 4813.470 ✅
  ขวา 3 (01:47-01:49): OC สูงสุด = 4812.875 < 4813.470 ✅
  body 01:45 = 24pip ≥ 2%R55(23pip) ✅
  → นับเป็น LH ✅
```

---

### 2.2 จุดเข้า BUY (เทรนขึ้น)

1. รอให้ราคาย่อตัวลงมาหลังจบเทรน
2. สังเกตหา **แท่งคู่ (กรอบสดใหม่)**
3. จดจำ **เนื้อเทียนด้านล่าง** → เรียกว่า **"จุดเทคนิค"**
4. รอให้ราคา **วกกลับมาแตะ Entry Zone**

#### เกณฑ์คุณภาพของ HL ที่ดี

> HL ที่จะใช้รอเข้า ต้องย่อตัวกลับจาก HH ก่อนหน้าในสัดส่วนที่เหมาะสม

```
ระยะย่อ = HH ก่อนหน้า − HL ปัจจุบัน (วัดเป็น pip)
สัดส่วน = ระยะย่อ ÷ Range55 × 100%

10% – 30% ของ Range55 → HL สวย ✅ รอเข้าได้
< 10%                  → ย่อน้อยเกิน → HL ไม่ชัด ❌
> 30%                  → ย่อลึกเกิน → อาจไม่ใช่แค่พักตัว ❌
```

```
ตัวอย่าง (V6):
  HH4 = 4,774.875 | HL4 = 4,759.618
  ระยะย่อ = (4,774.875 − 4,759.618) × 100 = 1,526 pip
  Range55  = 9,616 pip
  สัดส่วน  = 1,526 ÷ 9,616 = 15.9% → ✅ สวย อยู่ใน 10-30%
```

```
Buffer    = 100 pip (fixed)
Entry Zone = [จุดเทคนิค − 100pip  →  จุดเทคนิค + 100pip]

เงื่อนไขเข้า BUY:
  ราคา (ไส้เทียน) แตะเข้ามาใน Zone
  → เข้า BUY ทันที ไม่ต้องรอปิดแท่ง

ตัวอย่าง:
  จุดเทคนิค (HL4) = 4,759.618
  Entry Zone = [4,758.618 — 4,760.618]
  แท่ง 10:30 Low = 4,751.285 → ไส้ผ่าน Zone ระหว่างแท่ง
  → เข้า BUY ที่ ~4,760.618 ทันทีที่ราคาแตะ Zone
```

---

### 2.2.1 จุดเข้า SELL (เทรนลง) — Mirror จาก BUY

1. รอให้ราคาดีดตัวขึ้นมาหลังจบเทรน
2. สังเกตหา **แท่งคู่ (กรอบสดใหม่)** ด้านบน
3. จดจำ **เนื้อเทียนด้านบน** → เรียกว่า **"จุดเทคนิค"**
4. รอให้ราคา **ดีดขึ้นมาแตะ Entry Zone**

```
Buffer    = 100 pip (fixed)
Entry Zone = [จุดเทคนิค − 100pip  →  จุดเทคนิค + 100pip]

เงื่อนไขเข้า SELL:
  ราคา (ไส้เทียน) แตะเข้ามาใน Zone
  → เข้า SELL ทันที ไม่ต้องรอปิดแท่ง
```

---

### 2.3 การตั้ง Stop Loss (SL) — เทรนขึ้น/ลง

> **Range** = High สูงสุด - Low ต่ำสุด ของ **55 แท่ง** = 100%

| จุด SL | วิธีคำนวณ | ความปลอดภัย |
|--------|-----------|------------|
| **SL1** | ห่างจากจุดเทคนิค **10-20% ของ Range** | ปานกลาง |
| **SL2** | ห่างจากไส้เทียนของแท่งคู่ **10% ของ Range** | ปลอดภัยกว่า |
| **SL3** | ห่างจากไส้เทียนกลุ่มก่อนหน้า **10% ของ Range** | ปลอดภัยที่สุด |

> 💡 **SL ที่ดี = จุดที่ถ้าราคามาถึง หมายความว่าเราคิดผิดจริงๆ ไม่ใช่แค่สวิง**

---

### 2.4 การตั้ง Take Profit (TP) — เทรนขึ้น/ลง

> **เนื้อเทียนบนยอดก่อนหน้า** = Close ≈ Open ของ **แท่งคู่สูงสุด** ก่อนราคาพักตัว

| จุด TP | วิธีคำนวณ | ความเสี่ยง |
|--------|-----------|-----------|
| **TP1** | **30-40%** ของระยะจากจุดเทคนิค → ยอดก่อนหน้า | ต่ำ |
| **TP2** | **50%** ของระยะจากจุดเทคนิค → ยอดก่อนหน้า | ปานกลาง |
| **TP3** | ต่ำกว่าเนื้อเทียนบนยอดก่อนหน้าเล็กน้อย | สูง |

---

### 2.5 กฎ Risk:Reward (R:R)

- R:R ต้องเป็น **อย่างน้อย 1:1** ทุกครั้ง
- ถ้า R:R ไม่คุ้ม → **ปรับ TP หรือ SL** หรือ**ไม่เข้าเทรด**

**หลักการปรับ R:R ให้ได้ 1:1:**
- ถ้าหา **TP ที่เหมาะสม**ได้ก่อน → ใช้ **SL = ระยะ TP** (วัดจากจุดเข้า)
- ถ้าหา **SL ที่เหมาะสม**ได้ก่อน → ใช้ **TP = ระยะ SL** (วัดจากจุดเข้า)

```
Reward = TP - จุดเข้า
Risk   = จุดเข้า - SL
R:R    = Reward / Risk  → ต้องได้ >= 1.0

ถ้า R:R < 1.0 → ปรับ TP ขึ้น หรือ ปรับ SL เข้ามา หรือไม่เข้าเทรด
```

## Part 3 : เทคนิคอื่นๆ

### 3.1 ตามเจ้า (Breakout Follow)

#### นิยาม
เล่นตามเทรน ลักษณะคล้าย Breakout โดยสังเกตกลุ่มของราคาที่สร้างกรอบแนวต้านชัดเจน แล้วรอราคาหลุดออกจากกรอบ

#### ใช้ได้กับ / ห้ามใช้กับ

| ลักษณะ | ใช้ตามเจ้าได้ | หมายเหตุ |
|--------|-------------|---------|
| เทรนขึ้น | ✅ BUY | |
| เทรนลง | ✅ SELL | |
| ภูเขา | ✅ BUY | โซนล่างเท่านั้น |
| ไซเวย์กดลง | ❌ | ห้ามใช้ตามเจ้า |
| ไซเวย์ยกขึ้น | ❌ | ห้ามใช้ตามเจ้า |
| ไม่ชัด | ❌ | ไม่เทรด |

#### หลักการตีกรอบ
- ใช้ **เนื้อเทียน** เป็นจุดอ้างอิง
- **ขนาดกรอบ** = กรอบบน - กรอบล่าง = 100%

> ⚠️ **นิยาม "กรอบเล็กๆ" ในเทคนิคตามเจ้า:** กรอบที่ใช้ต้องมีขนาด **ไม่เกิน 35% ของ Range 55 แท่ง**

#### เงื่อนไข 2 จุดสัมผัส (บังคับ)

> **หลักการ:** ฝั่งที่ราคาต้องทะลุ ต้องถูก test อย่างน้อย 2 ครั้ง จึงจะถือว่าเป็นแนวต้าน/รับที่แข็งแกร่งพอ

```
ตามเจ้า BUY → สนใจกรอบบน
  กรอบบนต้องมี Swing High อย่างน้อย 2 จุด
  โดย body_hi ของ 2 จุดนั้น ห่างกัน ≤ 5% ของ Range55
  จุด Breakout = body_hi สูงสุดของ 2 จุดนั้น
  (กรอบล่าง ใช้ Swing Low ล่าสุดเพียง 1 จุดก็พอ)

ตามเจ้า SELL → สนใจกรอบล่าง
  กรอบล่างต้องมี Swing Low อย่างน้อย 2 จุด
  โดย body_lo ของ 2 จุดนั้น ห่างกัน ≤ 5% ของ Range55
  จุด Breakout = body_lo ต่ำสุดของ 2 จุดนั้น
  (กรอบบน ใช้ Swing High ล่าสุดเพียง 1 จุดก็พอ)

ถ้าฝั่งที่ต้องการมีจุดสัมผัสแค่ 1 จุด → ยังไม่เป็นกรอบที่ใช้ตามเจ้าได้ ❌
```

```
ตัวอย่าง ตามเจ้า BUY:
  SH-A body_hi = 4,782.005  ← test กรอบบนครั้งที่ 1
  SH-B body_hi = 4,786.715  ← test กรอบบนครั้งที่ 2
  ห่างกัน = 472 pip | 5%Range55 = 481 pip
  472 < 481 → ✅ 2 จุดสัมผัส → กรอบบน = 4,786.715
  SL = Swing Low ล่าสุด (ไม่ต้องมี 2 จุด)
```

#### จุดเข้า 3 รูปแบบ

> **นิยามสั้น vs ยาว** วัดจากระยะที่เนื้อเทียนหลุดพ้นกรอบบน

```
ระยะหลุด  = Close ของแท่ง Breakout − กรอบบน
สัดส่วน   = ระยะหลุด ÷ ขนาดกรอบ × 100%

< 5%       → ยังไม่นับว่า Breakout (หลุดไม่ชัด)
5% – 35%   → ตามเจ้าคอนเฟิร์มสั้น
> 35%      → ตามเจ้าคอนเฟิร์มยาว
```

**รูปแบบที่ 1 — ตามเจ้าในแท่ง**
1. รอกราฟชนะ **ไส้เทียนที่ยาวที่สุด** ของกลุ่มปัจจุบัน
2. รอย่อกลับมาที่ **ปลายไส้** แล้วเข้า (ไม่ต้องรอปิดแท่ง)

**รูปแบบที่ 2 — ตามเจ้าคอนเฟิร์มสั้น (ระยะหลุด 5–35% ของกรอบ)**
1. รอเนื้อเทียน **ปิดหลุดกรอบ 5–35%**
2. เมื่อเปลี่ยนแท่ง → **เปิด Position ทันที**

**รูปแบบที่ 3 — ตามเจ้าคอนเฟิร์มยาว (ระยะหลุด > 35% ของกรอบ)**
1. รอเนื้อเทียน **ปิดหลุดกรอบ > 35%** → ยังไม่เข้าทันที
2. รอย่อก่อน แล้วค่อยเข้า

| จุดเข้าคอนเฟิร์มยาว | ตำแหน่ง | ความเสี่ยง | โอกาสได้เข้า |
|---|---------|-----------|------------|
| **จุดที่ 1** | ครึ่งแท่งที่หลุดกรอบ | สูง | สูง |
| **จุดที่ 2** | บริเวณกรอบ | ต่ำ | ต่ำกว่า |

```
ตัวอย่าง:
กรอบบน=4,923.945 | กรอบ=1,589pip
แท่ง 20:10 Close=4,925.685
ระยะหลุด = 4,925.685 − 4,923.945 = 174pip
สัดส่วน  = 174 ÷ 1,589 = 11% → คอนเฟิร์มสั้น ✅
```

#### TP

| จุด TP | ตำแหน่ง |
|--------|---------|
| **TP1** | 1/3 ของขนาดกรอบที่หลุดออกมา |
| **TP2** | 1/2 ของขนาดกรอบที่หลุดออกมา |
| **TP3** | เท่ากับขนาดกรอบที่หลุดออกมา |

> 💡 สามารถปรับ TP ให้ R:R ≈ 1:1 โดยใช้ **TP = จุดเข้า + ระยะ SL**

#### SL — วัดจาก **กรอบบน** ลงมา

> ⚠️ **หลักการ:** SL วัดจากกรอบบนลงมา ไม่ใช่วัดจากจุดเข้า

| รูปแบบ | SL |
|--------|-----|
| **ตามเจ้าในแท่ง** | กรอบบน − 1/3 ของขนาดกรอบ |
| **ตามเจ้าคอนเฟิร์มสั้น** | กรอบบน − 1/2 ของขนาดกรอบ  หรือ  กรอบบน − 70% ของขนาดกรอบ |
| **ตามเจ้าคอนเฟิร์มยาว** | กรอบบน − 1/3 ของขนาดกรอบ  หรือ  กรอบบน − 1/2 ของขนาดกรอบ |

```
ตัวอย่าง: กรอบบน=4,923.945 | กรอบล่าง=4,908.055 | ขนาดกรอบ=1,589 pip

ตามเจ้าในแท่ง:      SL = 4,923.945 − 530 pip = 4,918.415
คอนเฟิร์มสั้น 1/2:  SL = 4,923.945 − 795 pip = 4,915.960
คอนเฟิร์มสั้น 70%:  SL = 4,923.945 − 1,112 pip = 4,912.825
คอนเฟิร์มยาว 1/3:  SL = 4,923.945 − 530 pip = 4,918.415
คอนเฟิร์มยาว 1/2:  SL = 4,923.945 − 795 pip = 4,915.960
```

#### กฎการเลือก R:R เมื่อมีหลายตัวเลือก SL

> **เลือก SL ที่ให้ R:R ใกล้เคียง 1 ที่สุด แต่ต้องไม่ต่ำกว่า 1.0**

```
ตัวอย่าง: Entry=4,925.665 | TP3=1,589 pip

SL 1/2  → Risk=925pip  → R:R = 1,589÷925 = 1.72
SL 70%  → Risk=1,284pip → R:R = 1,589÷1,284 = 1.24

→ เลือก SL 70% เพราะ R:R=1.24 ใกล้ 1 กว่า 1.72 และยังไม่ต่ำกว่า 1.0
```

> 💡 หลักการ: SL ที่ใหญ่กว่า = Risk มากกว่า = R:R ต่ำกว่า = ใกล้ 1 กว่า
> เลือก SL ที่ใหญ่ที่สุด โดยยังคงให้ R:R ≥ 1.0

- **SL ที่ดี = จุดที่ถ้าราคามาถึง หมายความว่าเราคิดผิดจริงๆ**

> 💡 เทคนิคนี้เน้นเก็บสั้น แต่ใช้ TF ใหญ่ขึ้นเก็บยาวได้

### 3.2 ไม้รวย

#### นิยาม
เทคนิคที่เหมาะสำหรับ **กราฟที่ไม่ชัด** หรือกราฟที่มีโอกาสทั้ง BUY และ SELL โดยรอจังหวะหลังราคาเคลื่อนที่แรงๆ แล้วย้อนกลับมาเพียงเล็กน้อย ก่อนเข้าเทรดตามทิศทางเดิม

**ทิศทางของไม้รวย — กำหนดจากแท่งพ่อเสมอ:**
| แท่งพ่อ | ทิศทางที่เล่น |
|--------|-------------|
| ราคา**เทลง**อย่างรุนแรงรวดเร็ว | เตรียมเล่น **BUY** เสมอ |
| ราคา**พุ่งขึ้น**อย่างรวดเร็ว | เตรียมเล่น **SELL** เสมอ |

หลักการ จุดเข้า TP/SL เหมือนกันทุกอย่าง แค่**สลับทิศทางตรงข้ามทั้งหมด**

> ⚠️ **ข้อระวัง — ห้ามใช้สวนเทรน:**
> "สวนเทรน" ในที่นี้หมายถึง **ทิศที่จะ "เปิด Position" สวนกับเทรนปัจจุบัน**
> ไม่ใช่ทิศของแท่งพ่อสวนกับเทรน — แท่งพ่อสวนทางกับเทรนเป็นเรื่องปกติของไม้รวย

**ตารางตรวจสอบ: เล่นได้หรือไม่?**

| เทรนปัจจุบัน | แท่งพ่อ | ทิศไม้รวย | สวนเทรน? | ผล |
|------------|--------|----------|---------|-----|
| ขึ้น | เทลง | BUY | ไม่สวน | ✅ เล่นได้ |
| ขึ้น | พุ่งขึ้น | SELL | สวน | ❌ ห้ามเล่น |
| ลง | เทลง | BUY | สวน | ❌ ห้ามเล่น |
| ลง | พุ่งขึ้น | SELL | ไม่สวน | ✅ เล่นได้ |
| ไม่ชัด | เทลง | BUY | ไม่มีเทรน | ✅ เล่นได้ |
| ไม่ชัด | พุ่งขึ้น | SELL | ไม่มีเทรน | ✅ เล่นได้ |

---

#### โครงสร้างของ "ไม้รวย"

ประกอบด้วย **3 ส่วน** หลัก:

```
[แท่งพ่อ] → [แท่งแม่] → [แท่งลูก]
```

---

#### ส่วนที่ 1 — แท่งพ่อ

แท่งเทียน **1-5 แท่ง** ที่ราคาเคลื่อนที่แรงและรุนแรงในทิศทางใดทิศทางหนึ่ง

> 💡 **ทิศทางแท่งพ่อ กำหนดทิศทางการเล่น:**
> - แท่งพ่อ **เทลง** → เตรียมเล่น **BUY**
> - แท่งพ่อ **พุ่งขึ้น** → เตรียมเล่น **SELL**

**เกณฑ์:**
- จำนวนแท่ง: **1-5 แท่ง**
- ระยะราคา: **50-100% ของ Range 55 แท่ง** (นับเฉพาะเนื้อเทียน Open-Close)
  - **< 50% ของ Range** → ไม่สวย ไม่ควรเล่น
  - **100% ของ Range** → สวยที่สุด
- วัดจาก: **Open ของแท่งแรกที่เริ่มเทลงรวดเดียว** → **Close ของแท่งสุดท้าย** ก่อนเกิดแท่งแม่

**ลักษณะแท่งพ่อที่ดี:**
- ยาวโดดเด่นกว่าแท่งอื่นในกราฟอย่างชัดเจน
- เคลื่อนที่ **รวดเดียวในทิศทางเดียว** ไม่มีการสวนทิศกลางทาง
- เนื้อเทียนหนา ไม่ใช่แค่ไส้
- กรณีหลายแท่ง: ทุกแท่งต้องเป็นสีเดียวกัน ไม่มีแท่งสวนทิศแทรก

> ⚠️ **จุดเริ่มต้นแท่งพ่อ** = จุดที่ราคา **เริ่มเทรวดเดียว** เท่านั้น ไม่ใช่จุดสูงสุดของ Range 55 แท่ง

> 💡 **กฎสำคัญ:** เมื่อเกิดแท่งพ่อที่ชัดเจน → **โฟกัสที่แท่งพ่อนั้นเลย** ลักษณะกราฟก่อนหน้า (เช่น ภูเขา หรือรูปแบบอื่น) หมดความสำคัญทันที — สนใจเฉพาะ ณ กราฟราคาปัจจุบันเท่านั้น

> ⚠️ **ข้อยกเว้น:** ถ้าแท่งพ่อลากราคาลงมาถึงระดับ **ฐานภูเขาด้านซ้าย** พอดี → ให้นับเป็น **ภูเขา BUY** ไม่ใช่ไม้รวย

```
ตัวอย่าง (จากรูป):
แท่งพ่อ: ราคาเทจาก ~4615 → ~4544
ระยะ = 71 USD = 7,100 pip ≈ เกือบเต็ม Range
```

---

#### ส่วนที่ 2 — แท่งแม่

แท่งเทียนที่ราคา **ปิดสวนทิศทาง** กับแท่งพ่อ มีขนาดเล็กกว่าแท่งพ่ออย่างชัดเจน

> 💡 นิยามชัดเจน: แท่งแม่ = แท่งที่ **ปิดสวนทิศทางกับแท่งพ่อ** เท่านั้น ไม่ใช่แค่แกว่งสวน

> ⚠️ **แท่งแม่มี 1 แท่งเท่านั้น** คือแท่งถัดจากแท่งพ่อทันที ไม่นับเป็นกลุ่มแท่ง

**เกณฑ์:**

| ระดับ | ขนาดแท่งแม่ (เทียบแท่งพ่อ) | การประเมิน |
|-------|--------------------------|-----------|
| **สวยที่สุด** | 10-20% ของแท่งพ่อ | ✅ ดีที่สุด |
| **ใช้ได้** | 20-40% ของแท่งพ่อ | ⚠️ ระวัง |
| **ไม่สวย (เล็กเกินไป)** | < 5% ของแท่งพ่อ | ❌ หลีกเลี่ยง |
| **ไม่สวย (ใหญ่เกินไป)** | > 40% ของแท่งพ่อ | ❌ หลีกเลี่ยง |

> ⚠️ **การวัดขนาดแท่งแม่** = นับเฉพาะ **เนื้อเทียน (Open-Close) เท่านั้น ไม่รวมไส้เทียน**

> 💡 **จุดเทคนิค** = บริเวณ Close ของแท่งพ่อ ≈ Open ของแท่งแม่ → ใช้เป็นจุดเตรียมเปิด Position

```
ตัวอย่าง (จากรูป):
แท่งแม่มีขนาดประมาณ 5% ของแท่งพ่อ → ถือว่าสวยมาก
```

---

#### ส่วนที่ 3 — แท่งลูก

แท่งที่เฝ้าสังเกตและรอเปิด Position ตามแผน — **แท่งถัดจากแท่งแม่เสมอ**

> 💡 แท่งลูก = จุดเข้าจริง ไม่ใช่แท่งแม่

---

#### จุดเข้า 4 รูปแบบ (อ้างอิง BUY)

| จุดเข้า | ตำแหน่ง | เหมาะกับ |
|--------|---------|---------|
| **จุดที่ 1** | เปิดเมื่อปิดแท่งแม่ | แท่งแม่มีขนาดเล็กมาก |
| **จุดที่ 2** | กึ่งกลางของแท่งแม่ | ต้องการเข้าเร็วกว่า |
| **จุดที่ 3** | จุดเทคนิค (Close พ่อ ≈ Open แม่) | **จุดมาตรฐาน** |
| **จุดที่ 4** | ต่ำกว่าจุดเทคนิค | **จุดได้เปรียบ** ราคาดีกว่า |

#### จุดเข้า 4 รูปแบบ (อ้างอิง SELL — สลับทิศทั้งหมด)

| จุดเข้า | ตำแหน่ง | เหมาะกับ |
|--------|---------|---------|
| **จุดที่ 1** | เปิดเมื่อปิดแท่งแม่ | แท่งแม่มีขนาดเล็กมาก |
| **จุดที่ 2** | กึ่งกลางของแท่งแม่ | ต้องการเข้าเร็วกว่า |
| **จุดที่ 3** | จุดเทคนิค (Close พ่อ ≈ Open แม่) | **จุดมาตรฐาน** |
| **จุดที่ 4** | สูงกว่าจุดเทคนิค | **จุดได้เปรียบ** ราคาดีกว่า |

#### ข้อสำคัญ — จุดเข้าจริงและการคำนวณ TP

> ⚠️ **จุดเข้าจริง** = ราคาที่แท่งลูก**ย่อลงมาถึงจริงๆ** ไม่ใช่แค่จุดเทคนิคที่คำนวณไว้
> - ถ้าแท่งลูกย่อลงมาแค่ ~4431 → จุดเข้าต่ำสุดที่ได้จริงคือ **4431** เท่านั้น

> 💡 **เมื่อรู้จุดเข้าจริงแล้ว ต้องคำนวณ TP ใหม่ทันที:**
> - Risk = จุดเข้า - SL
> - TP ต้องได้ Reward **≥ Risk** (R:R ≥ 1:1)
> - ถ้า TP เดิมที่คำนวณไว้ให้ R:R < 1:1 → **ปรับ TP ขึ้นไปจนได้ R:R = 1:1**

```
ตัวอย่าง:
จุดเข้าจริง = 4431 / SL = 4400
Risk = 4431 - 4400 = 31 USD
TP ต้องอยู่ที่ ≥ 4431 + 31 = 4462 จึงจะ R:R = 1:1
```

---

#### TP — Take Profit

| จุด TP | ตำแหน่ง (BUY) | ตำแหน่ง (SELL) | หมายเหตุ |
|--------|-------------|--------------|---------|
| **TP1** | 1/3 ของแท่งพ่อ (ขึ้น) | 1/3 ของแท่งพ่อ (ลง) | ต่ำความเสี่ยง |
| **TP2** | 1/2 ของแท่งพ่อ (ขึ้น) | 1/2 ของแท่งพ่อ (ลง) | ปานกลาง |
| **TP3** | เกือบถึงยอดสุดของแท่งพ่อ | เกือบถึงฐานล่างของแท่งพ่อ | สูง |

> 💡 **SELL:** วัด TP ลงจากจุดเข้า / **BUY:** วัด TP ขึ้นจากจุดเข้า — หลักการเดียวกัน สลับทิศ

> ⚠️ **ตรวจสอบอุปสรรคก่อนตั้ง TP เสมอ** — สังเกตจากแท่งคู่, กลุ่มราคาก่อนหน้า, ไส้เทียน หรือจุด Low เก่า ที่อาจเป็นแนวต้าน

**วิธีมองอุปสรรค (เรียงลำดับความสำคัญ):**
1. **แท่งคู่** ที่อยู่ใกล้ที่สุดในเส้นทางราคา → สำคัญที่สุด
2. **จุด Low เก่าที่ใกล้ที่สุด** (จุดต่ำสุดแรกก่อนราคาจะเทลงมา)
3. ไส้เทียนยาว หรือกลุ่มแท่งที่แออัด

> 💡 **หลักการ:** ตั้ง TP **ใต้อุปสรรค** เสมอ อย่าฝืนตั้ง TP เลยแนวต้านไป เพื่อให้ Winrate โดยรวมสูงขึ้น

```
ตัวอย่าง (จากรูป):
TP1 = 4563 (≈ 1/3 ของแท่งพ่อ)
อุปสรรคถัดไป: ปลายไส้ ~4580 และแท่งคู่ ~4586
→ ควรปิดกำไรก่อนถึงแนวต้าน ไม่ฝืนเก็บยาว
```

---

#### SL — Stop Loss

| จุด SL | วิธีตั้ง (BUY) | วิธีตั้ง (SELL) | เงื่อนไข |
|--------|-------------|--------------|---------|
| **SL1** | เลยปลายไส้**ต่ำสุด**ของแท่งพ่อ+แม่ ออกไป **5% ของ Range** | เลยปลายไส้**สูงสุด**ของแท่งพ่อ+แม่ ออกไป **5% ของ Range** | มาตรฐาน |
| **SL2** | ตั้งอยู่ **ในไส้ล่าง** (ระหว่างจุดต่ำสุด - จุดเทคนิค) | ตั้งอยู่ **ในไส้บน** (ระหว่างจุดสูงสุด - จุดเทคนิค) | เมื่อไส้ยาวมาก > 35% ของ Range |

> 💡 **SL2 ใช้เมื่อ:** ไส้ยาวมากจนตั้ง SL ปกติทำให้ R:R ไม่คุ้ม — ปรับให้สมดุลกับ TP ที่วางแผนไว้

> ⚠️ ถ้าไส้ก่อนหน้ายาวมากเกินไป → พิจารณา **ไม่เล่นตรงจุดนั้น** แล้วรอ Setup ใหม่

```
ตัวอย่าง (จากรูป):
SL = ~4535 (เลยปลายไส้ต่ำสุดออกไป)
ระยะ SL = 1,400 pip | TP1 = 1,400 pip → R:R = 1:1
```

---

#### สรุป R:R และการประเมิน Setup

```
Reward = TP - จุดเข้า
Risk   = จุดเข้า - SL
R:R    = Reward / Risk  → ต้องได้ >= 1.0

ถ้า R:R < 1.0 → ปรับ TP หรือไม่เข้าเทรด
```

#### ข้อสรุปการใช้ไม้รวย

| เงื่อนไข | การตัดสินใจ |
|---------|------------|
| กราฟไม่ชัด | ✅ เหมาะมาก |
| ตามเทรน | ✅ ใช้ได้ |
| สวนเทรน | ❌ ห้ามใช้เด็ดขาด |
| แท่งแม่ > 30% ของแท่งพ่อ | ❌ หลีกเลี่ยง |
| ไส้ยาวมาก > 35% Range | ⚠️ ใช้ SL2 หรือไม่เล่น |

## Part 4 : Risk Management

### 4.1 เงินทุนที่เหมาะสม
- เงินทุนขั้นต่ำที่เหมาะสมคือ **> 300 USD**

---

### 4.2 การบริหารรอบเทรด
- เทรดเพียง **1 แผนต่อครั้งเท่านั้น**
- จะเริ่มแผนใหม่ได้ก็ต่อเมื่อ **แผนก่อนหน้าสิ้นสุดลงแล้วเท่านั้น**
- ค้นหาจุดเข้าเทรดจาก**ทุก Timeframe** แล้วเลือก Setup ที่สวยที่สุด เมื่อเทียบกันใน M1, M5, M15, M30, H1, H4

---

### 4.3 ความเสี่ยงต่อแผน (Risk per Trade)
- ขาดทุนได้ **ไม่เกิน 10% ของพอร์ต** ต่อแผน

```
ตัวอย่าง:
พอร์ต 300 USD → ขาดทุนได้สูงสุด 30 USD ต่อแผน
```

---

### 4.4 Position Sizing (การคำนวณ Lot)

**สูตรคำนวณ Lot ทั้งหมด:**

```
Lot ทั้งหมด = จำนวนเงินที่เสียได้ (USD) / ระยะ SL (pip)

ตัวอย่าง:
SL = 900 pip | เสียได้ 30 USD
Lot ทั้งหมด = 30 / 900 = 0.03 lot

ถ้าเข้า 3 ไม้ → แต่ละไม้ใช้ 0.01 lot
```

---

### 4.5 ความเสี่ยงสะสม (Loss Limit)

| เงื่อนไข | การตัดสินใจ |
|---------|------------|
| แพ้ **ติดกัน 3 ไม้** | หยุดเทรด |
| ขาดทุนสะสม **> 30% ของพอร์ต** | หยุดเทรด |
| ขาดทุนรวม **> 50% ของพอร์ต** | หยุดเทรด |

---

### 4.6 การบริหารหลายไม้พร้อมกัน
- เปิดกี่ไม้ก็ได้ แต่ **รวมกันต้องไม่เกิน Lot ทั้งหมดที่คำนวณได้** จาก 4.4

---

### 4.7 การย้าย SL (Trailing / Breakeven)

| เงื่อนไข | การกระทำ |
|---------|---------|
| เก็บกำไร **≤ 3,000 pip** | ไม่จำเป็นต้องเลื่อน SL |
| เก็บกำไร **> 3,000 pip** และราคาไป **> 2,000 pip** | เลื่อน SL มาวางที่ **+500 pip (กำไร)** |
| หลังจากนั้น ราคาขยับทุก **1,000 pip** | เลื่อน SL เพิ่มขึ้น **1,000 pip** |

```
ตัวอย่าง:
TP > 3,000 pip → เมื่อราคาไป 2,000 pip → ย้าย SL มาที่ +500 pip
ราคาไป 3,000 pip → ย้าย SL มาที่ +1,500 pip
ราคาไป 4,000 pip → ย้าย SL มาที่ +2,500 pip
```

---

> ⚠️ **หมายเหตุ — พอร์ตทดลองหา Winrate:**
> ให้ใช้ **0.01 Lot เท่านั้น** ทุกไม้ โดยไม่คำนึงถึงการคำนวณ Lot ข้างต้น

### 5.1 ขั้นตอนหลัก (Master Flow)

```
INPUT  → รับข้อมูล OHLC ของ 55 แท่งเทียนย้อนหลังจากปัจจุบัน (ทุก TF ที่วิเคราะห์)
STEP 1 → คำนวณ Range = High สูงสุด − Low ต่ำสุด ของ 55 แท่ง (= 100%)
STEP 2 → วิเคราะห์ทรงกราฟ → ระบุลักษณะ 1 ใน 6 แบบ
STEP 3 → Route ไปยัง Branch ที่ตรงกับลักษณะ
STEP 4 → หา Setup และคำนวณ Entry / SL / TP
STEP 5 → ตรวจ R:R ≥ 1:1
STEP 6 → คำนวณ Lot
OUTPUT → ส่งสัญญาณ BUY หรือ SELL
```

**ลำดับ Priority เมื่อกราฟชัดเจน:**
> ลักษณะกราฟ → แท่งคู่ (จุดเข้าตามลักษณะ) → ตามเจ้า → ไม้รวย

**เมื่อกราฟไม่ชัด:**
> ไม้รวย → รอให้ชัดก่อน

### 5.2 Branch เทรนขึ้น

#### เงื่อนไขยืนยัน
- มี Higher High (HH) และ Higher Low (HL) ต่อเนื่องชัดเจน
- ความชันเฉลี่ยของเส้นสัมผัส High-High และ Low-Low อยู่ที่ **45-50 องศา**
- ตลอด 55 แท่งที่มองย้อนหลัง ไม่มีเทรนลงมาก่อนในช่วงต้น
- ความสวย 100% = ยก HH/HL สม่ำเสมอ ความชันใกล้ 45-50° → เข้าได้
- ความสวย ~60% = ยก HH/HL แต่หลุดออกจากความชันอ้างอิง → หลีกเลี่ยง

#### Logic การหา Setup (เรียงตาม Priority)

**แบบที่ 1 — แท่งคู่ (มาตรฐาน)**
```
1. รอราคาพักตัวหลังจบเทรน
2. หาแท่งคู่ในช่วงพักตัว
   - Open หรือ Close ของ 2 แท่ง ห่างกัน ≤ 10 pip
   - เนื้อเทียนแต่ละแท่ง ≥ 5% ของ Range 55 แท่ง
3. จุดเทคนิค = เนื้อเทียนด้านล่างของแท่งคู่
4. รอราคาย่อกลับมาแตะจุดเทคนิค ±Buffer
5. เข้า BUY
```

**แบบที่ 2 — ตามเจ้า (ถ้าไม่มีแท่งคู่)**
```
1. ระหว่างเทรน ราคาพักสร้างกรอบเล็ก ≤ 35% ของ Range
2. รอเนื้อเทียนปิดหลุดกรอบบน
3. เข้า BUY ทันที หรือรอย่อกลับมาแล้วค่อยเข้า
```

**แบบที่ 3 — ไม้รวย (ถ้าไม่มีทั้งสองแบบข้างต้น)**
> ดูรายละเอียดใน 5.6

#### คำนวณ Entry
```
Buffer     = min(Setup Range × 10%, 300 pip)
Entry Zone = จุดเทคนิค ± Buffer
Entry จริง = ราคาที่แท่งถัดไปย่อมาถึงจริงๆ ภายใน Entry Zone
```

#### คำนวณ SL
```
SL1 = เลยปลายไส้ต่ำสุดของแท่งคู่ออกไป 5% ของ Range   (มาตรฐาน)
SL2 = อยู่ในไส้ล่าง ระหว่างปลายไส้ถึงจุดเทคนิค        (ใช้เมื่อไส้ยาว > 35% Range)
SL3 = เลยไส้ของกลุ่มแท่งก่อนหน้าที่ยาวที่สุด 5% Range  (ปลอดภัยที่สุด)
```

#### คำนวณ TP
```
TP1 = 30-40% ของระยะจากจุดเทคนิค → ยอดก่อนหน้า
TP2 = 50%    ของระยะเดียวกัน
TP3 = ต่ำกว่าเนื้อเทียนบนยอดก่อนหน้าเล็กน้อย
→ เลือก 1 TP เท่านั้น · ตรวจอุปสรรคก่อนตั้ง TP ทุกครั้ง
```

#### สัญญาณ Output
```
Signal : BUY
Entry  : [ราคา]
SL     : [ราคา]  (ระยะ [X] pip)
TP     : [ราคา]  (ระยะ [X] pip)
R:R    : [X]
Lot    : [X]
Setup  : เทรนขึ้น — แท่งคู่ / ตามเจ้า / ไม้รวย
```

| HH / HL | LL / LH |
| ราคาย่อลง → แตะแท่งคู่ด้านล่าง | ราคาดีดขึ้น → แตะแท่งคู่ด้านบน |
| SL อยู่ใต้จุดเข้า | SL อยู่เหนือจุดเข้า |
| TP อยู่เหนือจุดเข้า | TP อยู่ใต้จุดเข้า |
| สัญญาณ BUY | สัญญาณ SELL |

### 5.4 Branch ไซเวย์กดลง / ไซเวย์ยกขึ้น

#### เงื่อนไขยืนยัน
```
ไซเวย์กดลง  : ขาลง 80-100% ของ Range ใน 3-10 แท่ง → กรอบ Sideway อยู่ส่วนล่าง
ไซเวย์ยกขึ้น : ขาขึ้น 80-100% ของ Range ใน 3-10 แท่ง → กรอบ Sideway อยู่ส่วนบน
เงื่อนไขร่วม : กรอบ Sideway ต้องมีขนาด ≤ 50% ของ Range 55 แท่ง
               ถ้ากรอบ > 50% → ไม่ชัด ไม่เทรด
```

#### ตีกรอบบน-ล่าง
```
สังเกตจากแท่งคู่ หรือจุดที่ราคาสัมผัสใกล้เคียงกันหลายครั้ง
กรอบบน = แนวต้านด้านบน
กรอบล่าง = แนวรับด้านล่าง
ขนาดกรอบ = กรอบบน - กรอบล่าง = 100%
```

#### Logic การตัดสินใจ
```
ราคาแตะกรอบบน  → เปิด SELL
ราคาอยู่กลางกรอบ → ไม่เทรด ❌  (ต้องรอให้ถึงขอบกรอบ ±Buffer ก่อน)
ราคาแตะกรอบล่าง → เปิด BUY
```

#### คำนวณ TP / SL
```
Buffer = min(ขนาดกรอบ × 10%, 300 pip)
TP1 = 1/3 ของขนาดกรอบ
TP2 = 1/2 ของขนาดกรอบ
TP3 = เต็มกรอบ (กรอบบน - กรอบล่าง)
→ เลือก 1 TP เท่านั้น · ตรวจอุปสรรคก่อนตั้ง TP
SL  = เลยไส้เทียนของกรอบออกไป 5-10% ของ Range
```

### 5.5 Branch ภูเขา

#### เงื่อนไขยืนยัน
```
- รูปร่างสามเหลี่ยมชัดเจน (ขาขึ้นแล้วขาลงภายใน 55 แท่ง)
- ความสูงภูเขา (ฐาน → ยอด) > 50% ของ Range 55 แท่ง
- ราคากลับมาถึงฐานภายใน ≤ 40 แท่ง = สวย
- BUY เท่านั้น
```

#### ระบุฐานซ้าย
```
ฐานซ้าย = แท่งคู่ที่ต่ำที่สุดภายใน 55 แท่ง
         = จุด Reference หลักของทุกการคำนวณ
```

#### Logic การเข้า
```
Buffer = min(ความสูงภูเขา × 10%, 300 pip)

รอขาขวาลงมา:
  ราคาเข้าสู่ Zone (ฐานซ้าย ± Buffer) → เข้า BUY ทันที
  ราคาสูงกว่า Zone มากกว่า Buffer      → รอต่อ ยังไม่นับเป็นภูเขา

หมายเหตุ: ถ้ามีไม้รวยที่ขาลงปลาย → accuracy สูงขึ้น แต่ไม่ใช่เงื่อนไขบังคับ
```

#### คำนวณ TP / SL
```
TP1 = 1/3 ของความสูงภูเขา (วัดจาก Entry ขึ้นไป)
TP2 = 1/2 ของความสูงภูเขา
TP3 = เกือบถึงยอดสุดของภูเขา
→ เลือก 1 TP · ตรวจอุปสรรค

SL1 = ห่างจากจุดเทคนิค 10-20% ของ Range
SL2 = ห่างจากไส้เทียนล่างแท่งคู่ฐาน 5% ของ Range
SL3 = ถ้ามีไส้ก่อนหน้ายาวกว่า → เลยไส้ที่ยาวที่สุดออกไป
```

### 5.6 Branch ไม้รวย

#### โครงสร้าง: พ่อ → แม่ → ลูก

---

#### ส่วนที่ 1 — ตรวจแท่งพ่อ

**เงื่อนไขแท่งพ่อ:**
```
จำนวนแท่ง : 1-5 แท่ง
ระยะราคา  : 50-100% ของ Range 55 แท่ง (วัดเฉพาะเนื้อเทียน Open-Close)
ลักษณะ   : ยาวโดดเด่นกว่าแท่งอื่น · เคลื่อนทางเดียวตลอด · เนื้อหนา สีเดียวกัน
วัดจาก   : Open แท่งแรกที่เริ่มเทรวดเดียว → Close แท่งสุดท้ายก่อนแม่
```

**กำหนดทิศทาง:**
```
แท่งพ่อเทลง  → ไม้รวย BUY
แท่งพ่อพุ่งขึ้น → ไม้รวย SELL
```

**Exception Check — ถ้าแท่งพ่อลงถึงฐานภูเขา:**
```
แท่งพ่อเทลงมาถึงระดับฐานภูเขาด้านซ้ายพอดี
→ นับเป็น "ภูเขา BUY" ไม่ใช่ไม้รวย
→ ใช้ Logic 5.5 แทน
```

**ตรวจสวนเทรน:**

> "สวนเทรน" = ทิศที่จะ **เปิด Position** สวนกับเทรนปัจจุบัน
> ไม่ใช่ทิศของแท่งพ่อสวนกับเทรน

| เทรนปัจจุบัน | แท่งพ่อ | ทิศไม้รวย | สวนเทรน? | ผล |
|------------|--------|----------|---------|-----|
| ขึ้น | เทลง | BUY | ไม่สวน | ✅ เล่นได้ |
| ขึ้น | พุ่งขึ้น | SELL | สวน | ❌ ห้ามเล่น |
| ลง | เทลง | BUY | สวน | ❌ ห้ามเล่น |
| ลง | พุ่งขึ้น | SELL | ไม่สวน | ✅ เล่นได้ |
| ไม่ชัด | เทลง | BUY | ไม่มีเทรน | ✅ เล่นได้ |
| ไม่ชัด | พุ่งขึ้น | SELL | ไม่มีเทรน | ✅ เล่นได้ |

```
ถ้าสวนเทรน → ห้ามเข้า · รอสัญญาณจาก Branch อื่นแทน
```

> ⚠️ **กฎสำคัญ:** เมื่อเกิดแท่งพ่อชัดเจน → โฟกัสที่แท่งพ่อนั้นทันที
> ลักษณะกราฟก่อนหน้า (ภูเขา, ไซเวย์ ฯลฯ) หมดความสำคัญ

---

#### ส่วนที่ 2 — ตรวจแท่งแม่

```
แท่งแม่ = แท่งเดียวที่ถัดจากแท่งพ่อทันที (1 แท่งเท่านั้น)
เงื่อนไข:
  - ปิดสวนทิศทางกับแท่งพ่อ
  - ขนาดเนื้อเทียน (ไม่รวมไส้) อยู่ที่ 10-40% ของแท่งพ่อ
```

| ขนาดแท่งแม่ (เทียบพ่อ) | ระดับ |
|----------------------|-------|
| 10-20% | ✅ สวยที่สุด |
| 20-40% | ⚠️ ใช้ได้ |
| < 5% หรือ > 40% | ❌ หลีกเลี่ยง |

```
ถ้าแม่ไม่ผ่านเกณฑ์ → ไม่นับเป็นไม้รวย → รอแท่งพ่อใหม่
```

---

#### ส่วนที่ 3 — เข้า Position ที่แท่งลูก

**จุดเทคนิค:**
```
จุดเทคนิค = บริเวณ Close ของแท่งพ่อ ≈ Open ของแท่งแม่
```

**จุดเข้า 4 แบบ (อ้างอิง BUY / SELL สลับทิศ):**

| จุดเข้า | ตำแหน่ง | เหมาะกับ |
|--------|---------|---------|
| จุดที่ 1 | Open แท่งลูก (ปิดแท่งแม่แล้วเปิดทันที) | แม่เล็กมาก |
| จุดที่ 2 | กึ่งกลางของแท่งแม่ | ต้องการเข้าเร็ว |
| จุดที่ 3 | จุดเทคนิค | **มาตรฐาน** |
| จุดที่ 4 | ต่ำกว่า (BUY) / สูงกว่า (SELL) จุดเทคนิค | **จุดได้เปรียบ** |

**Entry จริงและการคำนวณ TP:**
```
Entry จริง = ราคาที่แท่งลูกย่อ/ดีดมาถึงจริงๆ ไม่ใช่จุดเทคนิคที่วางแผนไว้
→ เมื่อรู้ Entry จริงแล้ว ต้องคำนวณ TP ใหม่ทันที ให้ R:R ≥ 1:1
```

**คำนวณ TP:**
```
TP1 = 1/3 ของแท่งพ่อ
TP2 = 1/2 ของแท่งพ่อ
TP3 = เกือบถึงยอด/ฐานสุดของแท่งพ่อ
→ เลือก 1 TP · ตรวจอุปสรรคในเส้นทางราคา
```

**คำนวณ SL:**
```
SL1 = เลยปลายไส้สุดของแท่งพ่อ+แม่ รวมกัน ออกไป 5% ของ Range  (มาตรฐาน)
SL2 = อยู่ในไส้ (ระหว่างปลายไส้ถึงจุดเทคนิค)                  (ใช้เมื่อไส้ > 35% Range)
```

### 5.7 กฎ Universal (ใช้กับทุก Branch)

#### Buffer Rule
```
Buffer = min(Setup Range × 10%, 300 pip)

Setup Range คือ:
  เทรน   → ระยะจากจุดเทคนิคถึง TP3
  ไซเวย์ → ขนาดกรอบบน-ล่าง
  ภูเขา  → ความสูงภูเขา (ฐาน → ยอด)
  ไม้รวย → ขนาดแท่งพ่อ
```

#### R:R Rule
```
Reward = TP - Entry
Risk   = Entry - SL (BUY) หรือ SL - Entry (SELL)
R:R    = Reward ÷ Risk → ต้องได้ ≥ 1.0 ทุกครั้ง

ถ้า R:R < 1.0 → เลือกอย่างใดอย่างหนึ่ง:
  1. ปรับ TP ขึ้น (ถ้าไม่ติดอุปสรรค)
  2. ปรับ SL เข้ามา (ถ้า Setup ยังแข็งแกร่ง)
  3. ไม่เข้าเทรด
```

#### Lot Calculation
```
Risk Amount = พอร์ต × 10%
Lot         = Risk Amount ÷ ระยะ SL (pip)

ตัวอย่าง: พอร์ต 300 USD · SL = 900 pip
  Risk Amount = 30 USD
  Lot         = 30 ÷ 900 = 0.03 lot

⚠️ พอร์ตทดลองหา Winrate: ใช้ 0.01 Lot ทุกไม้คงที่
```

#### Setup Priority
```
กราฟชัด : ลักษณะกราฟ → แท่งคู่ → ตามเจ้า → ไม้รวย
กราฟไม่ชัด : ไม้รวย → รอให้ชัด

เลือก 1 Setup เท่านั้น ต่อ 1 แผน
เริ่มแผนใหม่ได้เมื่อแผนเดิมสิ้นสุด (SL หรือ TP โดน) เท่านั้น
```
