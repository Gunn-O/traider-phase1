ขั้นตอน 1 — เตรียม MT5 ก่อนเปิด Launcher

⚠️ สำคัญ: ต้องทำใน MT5 ทุกครั้ง ก่อน เปิด Launcher
  1. เปิด MT5 EXNESS (Launcher จะเปิดให้อัตโนมัติถ้ายังไม่เปิด)
  2. Login เข้า account (Cent หรือ Real ตาม mode ที่จะใช้)
  3. กดปุ่ม "Algo Trading" บน toolbar ให้เป็น สีเขียว ▶
    • ถ้าเป็นสีเทา/แดง → bot ส่ง order ไม่ได้ (จะ raise RuntimeError: trade_allowed=False)
  4. ตรวจ Market Watch ต้องมี symbol XAUUSDc (Cent) — คลิกขวา → Show
  5. ตรวจ Tools → Options → Expert Advisors → ✅ Allow algorithmic trading

ขั้นตอน 2 — เปิด Launcher

วิธีที่ 1: ดับเบิ้ลคลิก Tra(i)der บน Desktop (shortcut)

วิธีที่ 2: ดับเบิ้ลคลิก TraiderLauncher.exe ที่ root โปรเจกต์

หน้าต่าง Launcher จะแสดง 3 บรรทัด status:

Serviceสิ่งที่ launcher ทำ
MT5 Terminalตรวจ → ถ้าไม่เปิด → start อัตโนมัติ
Backend API (8080)เริ่ม api_server.py ผ่าน venv python
Frontend UI (3000)เริ่ม npm run dev ใน frontend/
กดปุ่ม ▶ Start All → รอจนทั้ง 3 ขึ้น ✅ → browser เปิดอัตโนมัติที่ http://localhost:3000

ขั้นตอน 3 — ใช้งาน Dashboard

Launcher ไม่ start bot อัตโนมัติ — มันแค่เตรียม infrastructure. ต้องไป dashboard เอง.
  • เปิด trade: TopBar → เลือก mode (Paper/Sim/Live) → Symbol → Timeframe → กด ▶ Start Bot
  • Backtest: เมนู Backtest → เลือก start/end/timeframe → Run
  • ดู open orders: หน้า Dashboard

ขั้นตอน 4 — Emergency Stop (เรียงลำดับจากเบาไปแรง)

🟢 Level 1 — Graceful Stop (จากหน้าเว็บ)
  • ปุ่ม ⏹ Stop Bot ใน TopBar → POST /api/stop
  • Bot หยุดรับ signal ใหม่ — order ที่เปิดอยู่ยังอยู่ (broker ปิดเองเมื่อ SL/TP hit)
  • ใช้เมื่อ: อยากหยุดเทรดต่อ แต่ปล่อย position ปัจจุบันรันต่อ
🟡 Level 2 — Emergency Stop (จากหน้าเว็บ)
  • ปุ่ม 🚨 Emergency Stop → POST /api/emergency-stop
  • ⚠️ implementation ปัจจุบันยังไม่ปิด position จริงที่ broker — แค่ clear state ใน memory
  • ต้องไปปิด manual ใน MT5 Desktop ด้วย
🟠 Level 3 — ปิดทุกอย่างทาง Launcher
  • กดปุ่ม ⏹ Stop All ใน Launcher → kill backend + frontend processes
  • MT5 Terminal ไม่ถูกปิด — TP/SL ที่ broker ยังทำงานปกติ (server-side)
🔴 Level 4 — ปิด Order ฉุกเฉินทั้งหมดใน MT5
  1. MT5 → tab Trade → Right-click ที่ position → Close Position (ทีละไม้)
  2. หรือ: tab Trade → Ctrl+A → Right-click → Close — ปิดทุกตัวพร้อมกัน
  3. ปิดปุ่ม Algo Trading (กดให้เป็นสีแดง) → bot ส่ง order ใหม่ไม่ได้
⛔ Level 5 — Kill ทุกอย่างจาก Task Manager

ถ้า launcher ค้าง: Task Manager → kill terminal64.exe + python.exe + node.exe
